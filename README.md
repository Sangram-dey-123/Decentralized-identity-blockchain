# Decentralized Identity Management System Using Blockchain

## Project Overview

This project presents a Python-based prototype of a decentralized
identity management system using blockchain concepts.

## Main Features

- Decentralized Identity (DID) creation
- Digital credential issuance
- SHA-256 credential hashing
- Credential verification
- Tamper detection
- Credential revocation
- Access control
- Audit trail
- Blockchain integrity validation
- Cross-sector credential management
